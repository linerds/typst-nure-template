# Курсова

| | Модуль | Перелік джерел |
| --- | --- | --- |
| Курсова робота | `cw` | ДСТУ 3008:2015 (`style: "3008"`) |
| Комплексний курсовий проєкт (нова форма ХНУРЕ) | `cw-v2` | ДСТУ 8302:2015 (`style: "8302"`) |

Порядок: титулка → завдання → календарний план → реферат → зміст → вступ → розділи → висновки → перелік джерел → додатки. Титулка, завдання й календарний план самі закінчуються розривом сторінки; після реферату нову сторінку починає зміст. Якщо методичка кафедри вимагає інший склад -- прибери чи заміни блок (див. [api.md](api.md#власна-сторінка)).

## Додаткові дані

| Поле | Де | Навіщо |
| --- | --- | --- |
| `initial-date`, `done-date` | `doc.toml` або `work(...)` | Дата видачі завдання і термін здачі; рік з `done-date` іде на титулку |
| `course`, `semester` | автор | Сторінка завдання |
| `full-name-gen` | автор | ПІБ у родовому: «Косач Лариси Петрівни» |
| `full-name-dat` | автор, `cw-v2` | ПІБ у давальному (типово `full-name-gen`) |
| `display-name` | автор і викладачі, `cw-v2` | «Лариса КОСАЧ» (типово `name`) |
| `committee-members` | `doc.toml` або `work(...)`, `cw-v2` | Члени комісії; типово всі викладачі, крім першого |

Перший викладач у `mentors` -- керівник. Дати в `doc.toml` -- без лапок і до `[[authors]]`:

```toml
subject = "БД"
initial-date = 2026-09-15
done-date = 2026-12-27
```

У `main.typ`: `initial-date: datetime(year: 2026, month: 9, day: 15)`.

## Курсова робота (`cw`)

```typst
#import "@vendor/nure:0.3.0": *

#let w = work(..toml("doc.toml"), title: "Інформаційна система «Помічник класного керівника»")

#set document(..w.document)
#show: style.dstu.with(skip: 1)

#cw.title-page(w)

#cw.task(
  w,
  source: [методичні вказівки, вимоги до системи, ...],
  content: [вступ, аналіз предметної області, ...],
  graphics: [діаграма класів, ER-діаграма, ...],
)

#cw.calendar-plan(w, table(
  columns: 4,
  align: (center, left, center, center),
  [№], [Назва етапів], [Строк виконання], [Примітки],
  [1], [Аналіз предметної області], [15.09 -- 24.09], [Виконано],
  [2], [Проєктування бази даних], [24.09 -- 18.10], [Виконано],
))

#cw.abstract(w, keywords: ("база даних", "веб-застосунок", "GO", "SQL"))[
  Мета роботи -- ...
]

#cw.contents()

#utils.nheading[Вступ]
...

= Аналіз предметної області
...

#utils.nheading[Висновки]
...

#bib(path("bibl.yml"), style: "3008")

#show: style.appendices
= Код програми
...
```

| Блок | Сторінка |
| --- | --- |
| `cw.title-page(w)` | «Пояснювальна записка до курсової роботи», тема, виконавець, керівник, комісія |
| `cw.task(w, source:, content:, graphics:)` | Завдання; потребує `initial-date` і `done-date` |
| `cw.calendar-plan(w, table, approval-date: auto)` | Ваша таблиця й підписи; `auto` -- дата з `done-date` |
| `cw.abstract(w, keywords: (...))[текст]` | Реферат: підсумки документа, ключові слова великими літерами за абеткою, текст |
| `cw.contents()` | Зміст |

## Комплексний курсовий проєкт (`cw-v2`)

```typst
#import "@vendor/nure:0.3.0": *

#let w = work(
  ..toml("doc.toml"),
  title: "Демонстраційна інформаційна система для комплексного курсового проєкту",
  committee-members: (
    (name: "Сосюра В. М.", degree: "Доц."),
    (name: "Симоненко В. А.", degree: "Ст. викл."),
  ),
  initial-date: datetime(year: 2026, month: 9, day: 15),
  done-date: datetime(year: 2026, month: 12, day: 27),
)

#set document(..w.document)
#show: style.dstu.with(skip: 1)

#cw-v2.title-page(w)

#cw-v2.task(
  w,
  source: [Узагальнити модель предметної області, визначити основні сутності.],
  content: [Опис предметної галузі, формування вимог, проєктування, тестування.],
)

#cw-v2.calendar-plan(w, table(
  columns: (0.7fr, 5.8fr, 2.5fr, 1.6fr),
  [№], [Назва етапів роботи], [Термін виконання], [Примітка],
  [1], [Аналіз предметної галузі], [], [виконано],
))

#cw-v2.abstract(
  w,
  keywords: (("веб-застосунок", "WEB APPLICATION"), ("курсова робота", "COURSEWORK")),
)[
  Мета даної роботи -- ...
][
  The purpose of this work is ...
]

#cw-v2.contents()

= Моделювання
...

#bib(path("bibl.yml"), style: "8302")

#show: style.appendices
= Приклад звіту
...
```

| Блок | Сторінка |
| --- | --- |
| `cw-v2.title-page(w)` | Факультет, кафедра, рівень вищої освіти, тема, здобувач, спеціальність, освітня програма, керівник, члени комісії |
| `cw-v2.task(w, source:, content:)` | Завдання; потребує `done-date`; перенесені рядки підкреслюються самі |
| `cw-v2.calendar-plan(w, table)` | Календарний план, дата видачі (`initial-date`) і підписи |
| `cw-v2.abstract(w, keywords: (...), en-keywords: none)[укр][англ]` | Реферат; з англійським текстом заголовок «РЕФЕРАТ / ABSTRACT» |
| `cw-v2.contents()` | Зміст; додатки як «Додаток А Назва» без підрозділів |

- `title`, `source`, `content` -- текст або вміст; кожен перенесений рядок підкреслюється автоматично.
- `keywords` -- пари `(укр, англ)` або рядки з окремими `en-keywords: ("test", "template")`.
- `faculty`, `education-level`, `program-type`, `program-name` мають типові значення ХНУРЕ; змінюй у `work`, лише якщо треба.

## Реферат і підсумки

Рядок «Пояснювальна записка містить: N с., N табл., N рис., N джерел» рахується сам (нулі пропускаються): усі сторінки; таблиці-`figure` (зокрема `tab`); рисунки `figure(image(...))` (зокрема `fig`); різні джерела, на які є `@ключ` у тексті (з `bib(..., full: true)` -- усі записи переліку). Ключові слова сортуються самі (кирилиця за українською абеткою, далі латиниця) і переводяться у верхній регістр -- пиши звичайним регістром у будь-якому порядку.

## Нумерація сторінок

`style.dstu.with(skip: 1)` -- без номера лише титулка, решта (завдання, реферат) від 2. Інакше за вимогою кафедри: `skip` (скільки перших сторінок без номера) або `offset` (зсув номерів).

## Рецепти

Те саме одним викликом; використовуй, лише якщо нічого не треба змінювати:

```typst
#show: coursework.with(
  title: "...",
  subject: "БД",
  authors: (...),
  mentors: (...),
  task-list: (done-date: ..., initial-date: ..., source: [...], content: [...], graphics: [...]),
  calendar-plan: (plan-table: table(...), approval-date: ...),
  abstract: (keywords: (...), text: [...]),
  bib-path: path("bibl.yml"),
  appendices: [= Код програми ...],
)

= Розділ 1
...
```

`coursework-v2` додатково приймає `committee-members`, `abstract-en: (keywords: ..., text: ...)`, `faculty`, `education-level`, `program-type`, `program-name`. Додатки в рецептах -- аргументом `appendices`, бо перелік джерел мусить стояти перед ними.
