# Дані роботи

Усе для титулок і службових сторінок описується один раз і передається у `work`:

```typst
#let w = work(..toml("doc.toml"), type: "ЛБ", number: 2, title: "...")
```

`..toml("doc.toml")` розгортає поля файлу як аргументи; поле після `..toml(...)` має перевагу над однойменним полем файлу. У `doc.toml` -- спільне для дисципліни (університет, дисципліна, автори, викладачі), у `main.typ` -- `type`, `number`, `title`.

## Формат `doc.toml`

```toml
subject = "СМП"            # поля роботи -- НА ПОЧАТКУ файлу
done-date = 2026-12-27     # дата без лапок, інакше це рядок

[[authors]]
name = "Косач Л. П."

[[mentors]]
name = "Шевченко Т. Г."
```

Поле після `[[authors]]`/`[[mentors]]` належить цьому блоку: дописане в кінець файлу `subject = …` тихо потрапить до останнього викладача, і `work` його не побачить.

## Поля роботи

| Поле | Приклад | Опис |
| --- | --- | --- |
| `university` | `"ХНУРЕ"` | Код університету, типово `"ХНУРЕ"` |
| `edu-program` | `"КУІБ"` | Освітня програма; типово -- першого автора |
| `subject` | `"СМП"` | Скорочення дисципліни; невідоме виводиться як є |
| `type` | `"ЛБ"` | `ЛБ` -- «Звіт з лабораторної роботи», `ПЗ` -- «Звіт з практичної роботи», `КР` -- «Контрольна робота», `ІДЗ` -- «Індивідуальне домашнє завдання»; інше -- як є |
| `number` | `2` | Номер роботи |
| `title` | `"Потік керування"` | Тема (рядок або вміст `[...]`); `none` -- без теми |
| `authors` | | Автори |
| `mentors` | | Викладачі; перший -- керівник |
| `committee-members` | | Члени комісії (`cw-v2`); типово -- усі викладачі, крім першого |
| `initial-date`, `done-date` | `2026-09-15` | Дати видачі й здачі (курсові) |
| `year` | `2026` | Рік на титулці; типово з `done-date` або поточний |
| `city` | `"Харків"` | Місто на титулці; типово -- місто університету; `none` прибирає |
| `faculty`, `education-level`, `program-type`, `program-name` | | Для `cw-v2`, мають типові значення ХНУРЕ |
| `data` | `yaml("data.yaml")` | Власні дисципліни, програми, університети |

## Автори

```toml
[[authors]]
name = "Косач Л. П."
edu-program = "КУІБ"
group = "24-1"
gender = "f"
variant = 8
course = 2
semester = 4
full-name-gen = "Косач Лариси Петрівни"
full-name-dat = "Косач Ларисі Петрівні"
display-name = "Лариса КОСАЧ"
```

| Поле | Обов'язкове | Де використовується |
| --- | --- | --- |
| `name` | так | Скрізь: «Прізвище І. Б.» (на це покладається `mise run rename`) |
| `edu-program` | так | Шифр групи, кафедра, спеціальність |
| `group` | так | `"24-1"` + `edu-program` → «КУІБ-24-1»; можна й повністю `"КУІБ-24-1"` |
| `gender` | так | `"m"` -- «Виконав», `"f"` -- «Виконала»; кілька авторів -- «Виконали» |
| `variant` | ні | «Варіант №8» на титулці звіту |
| `course`, `semester` | курсові | Сторінка завдання |
| `full-name-gen` | курсові | ПІБ у родовому відмінку |
| `full-name-dat` | ні | ПІБ у давальному (`cw-v2`); типово `full-name-gen` |
| `display-name` | ні | «Власне ім'я ПРІЗВИЩЕ» (`cw-v2`); типово `name` |

Кілька авторів -- кілька блоків `[[authors]]`: на титулці звіту всі, у курсових перший.

## Викладачі

```toml
[[mentors]]
name = "Шевченко Т. Г."
degree = "Доцент кафедри ПІ"
gender = "m"
display-name = "Тарас ШЕВЧЕНКО"
```

`name` обов'язкове; `degree` -- посада; `gender` обов'язкове, якщо викладач один («Перевірив»/«Перевірила», для кількох -- «Перевірили»); `display-name` -- для `cw-v2`. Члени комісії мають ті самі поля, крім `gender`.

## Вбудовані дані

`src/config/universities.yaml` пакунка: ХНУРЕ, освітні програми ПЗПІ, КУІБ, КНТ і понад 80 дисциплін зі скороченнями. У тексті:

```typst
#w.subject-name                                // Скриптові мови програмування
#w.edu.department-gen                          // кафедра в родовому відмінку
#universities.at("ХНУРЕ").subjects.at("БД")    // Бази даних
```

Якщо на титулці замість повної назви дисципліни скорочення -- її немає у вбудованих даних: додай через `data.yaml`.

## Власні дисципліни й університети

`data.yaml` поруч із `main.typ` (у mise -- у `src/`), записи накладаються на вбудовані:

```yaml
ХНУРЕ:
  subjects:
    ОЗСОС: Основи захисту сучасних операційних систем
  edu-programs:
    ПЗПІ:
      code: F2          # змінити одне поле
    ШІ:                 # додати програму
      name-long: Штучний інтелект
      department-gen: Штучного інтелекту
      code: 122
    КНТ: null           # прибрати програму

КПІ:                    # додати університет
  name: Національний технічний університет України «Київський політехнічний інститут імені Ігоря Сікорського»
  city: Київ
  edu-programs:
    ІПЗ:
      name-long: Інженерія програмного забезпечення
      department-gen: Інформатики та програмної інженерії
      code: 121
  subjects:
    ОП: Основи програмування
```

```typst
#let w = work(..toml("doc.toml"), type: "ЛБ", number: 2, data: yaml("data.yaml"))
```

| Запис | Обов'язкові поля | Необов'язкові |
| --- | --- | --- |
| Університет | `name` | `city`, `edu-programs`, `subjects` |
| Освітня програма | `name-long`, `department-gen`, `code` | `description` (спеціальність для макета `"complex"`), `program-name` |

Чого бракує, `work` повідомить з назвою поля.

## Поля, що повертає `work`

Ті самі поля плюс: `w.uni` (дані університету), `w.edu` (дані програми: `name-long`, `department-gen`, `code`, …), `w.subject-name`, `w.program-name`, `w.year`, `w.city`, `w.document` (для `#set document(..w.document)`).

Свої поля: `#let w = work(..toml("doc.toml")) + (consultant: "Драч І. Ф.")`, далі `#w.consultant`.
