# Розмітка тексту

Усе нижче діє після `#show: style.dstu`. Решта -- звичайний Typst.

## Короткі назви

| Коротко | Повна назва | Що робить |
| --- | --- | --- |
| `fig` | `dstu-figure` | Рисунок з підписом, приміткою й джерелом |
| `tab` | `dstu-table` | Таблиця з назвою, шапкою і приміткою |
| `note` | `dstu-note` | Примітка або кілька приміток |
| `bib` | `dstu-bibliography` | Перелік джерел |

Це ті самі функції; у тексті роботи пиши короткі.

## Сторінка й шрифт (робить шаблон)

А4; поля: верх і низ 20 мм, ліве 25 мм, праве 10 мм; номер сторінки вгорі праворуч. Times New Roman 14 pt, за шириною, абзацний відступ 1,25 см, без переносів. Код -- Courier New 11 pt. За відсутності шрифтів -- Liberation Serif/Mono з попередженням Typst.

## Заголовки

```typst
= Аналіз предметної області <sec:analysis>  // 1 АНАЛІЗ ПРЕДМЕТНОЇ ОБЛАСТІ -- з нової сторінки, по центру
== Огляд аналогів <sub:analogues>           // 1.1 Огляд аналогів
=== Перший аналог <pt:first>                // 1.1.1 Перший аналог
#utils.nheading[Вступ]                      // ВСТУП -- без номера, у змісті
```

- Перший рівень завжди з нової сторінки й великими літерами (пиши звичайним регістром -- шаблон переведе).
- Ненумеровані структурні елементи («Вступ», «Висновки», «Перелік скорочень») -- `#utils.nheading[...]`, не `= Вступ`.
- Під ненумерованим першим рівнем підзаголовки нумеруються `1`, `1.1` (без «0.»).
- Заголовок не лишається останнім рядком сторінки -- шаблон переносить його разом із текстом.
- Нумерація рисунків, таблиць, формул і лістингів скидається з кожним розділом («Рисунок 2.1»). Наскрізна («Рисунок 1», «(1)») -- `style.dstu.with(section-numbering: false)`.
- Між суміжними заголовками -- `#v(-spacing)` (потрібен `#import style: spacing`):

```typst
== Хід роботи
#v(-spacing)
=== Підготовка
```

- Перший рівень без номера, без розриву сторінки, звичайним накресленням (за вимогою кафедри): `#show: style.overrides.plain-heading`, краще разом із `section-numbering: false`.

## Списки

```typst
+ перший пункт;      // а) перший пункт;
+ другий пункт:      // б) другий пункт:
  + вкладений;       //    1) вкладений;
- маркер.            // – маркер.
```

Літери української абетки → цифри з дужкою → тире; кожен рівень зсунуто на 1,25 см; перенесені рядки від лівого берега. Пунктуацію ставить автор: мала літера, `;`, останній пункт з `.`.

## Рисунки

```typst
#fig(path("figures/scheme.png"), [Схема роботи], none, label: <fig:scheme>)
// Рисунок 1.1 – Схема роботи (рисунок виконано самостійно)

#fig(path("figures/net.png"), [Топологія мережі], "cisco.com", width: 80%)
// Рисунок 1.2 – Топологія мережі (за даними cisco.com)

#fig(path("figures/logo.png"), [Логотип])
// Рисунок 1.3 – Логотип

#fig(
  path("figures/arch.svg"),
  [Архітектура мікросервісу],
  none,
  note: [Обмін між шлюзом і сервісом відбувається за протоколом gRPC.],
  label: <fig:arch>,
  width: 92%,
)
```

- `fig(file, caption, source, note: none, label: none, ..args)`; `file` -- лише `path(...)`, рядок дає помилку з підказкою.
- `source`: не вказано або `()` -- без примітки; `none` -- «(рисунок виконано самостійно)»; рядок -- «(за даними …)».
- `note:` -- примітка або масив приміток під зображенням перед назвою (7.5.9).
- `label:` -- мітка; без неї рисунок мітки не має (з назви файлу мітка не утворюється).
- Решта аргументів (`width`, `height`, `fit`) іде в `image`.
- Альтернатива з тим самим оформленням: `#figure(image("figures/scheme.png", width: 80%), caption: [Схема роботи]) <fig:scheme>`.

## Таблиці

```typst
#tab(
  caption: [Порівняння режимів кешування],
  columns: (2.2fr, 1.5fr, 1.5fr),
  align: (left, center, center),
  header: ([Режим], [Затримка, мс], [RPS]),
  note: [Середнє значення за 10 000 запитів при 64 потоках.],
  label: <tab:perf>,
  [Без кешу], [42,5], [1 480],
  [In-memory], [4,1], [15 200],
)
```

- `caption`, `columns`, `header` (масив комірок шапки) обов'язкові; `note:` -- примітка в межах таблиці під основною частиною (не повторюється при переносі); `label:` -- мітка (старе `tag: "x"` теж працює); решта (`align`, `stroke`, комірки) іде в `table`.
- Назва «Таблиця 1.1 – …» над таблицею з абзацного відступу; таблиця ліворуч.
- Довга таблиця сама переноситься: шапка повторюється, на наступних сторінках «Продовження таблиці 1.1», на останній «Кінець таблиці 1.1». Не розбивай вручну, не став `placement: top` (плаваюча не розривається й напису не отримує).
- Десяткові дроби в комірках пиши з комою (`[42,5]`) -- поза формулами шаблон крапку не замінює.
- Таблиця з CSV: `..csv("assets/table.csv").flatten()` як комірки (шапку передай окремо в `header:`, а з даних прибери).
- Складна шапка (`colspan`/`rowspan`) -- звичайний `figure` з обов'язковим `table.header(...)`:

```typst
#figure(
  table(
    columns: 3,
    table.header([Параметр], [Значення], [Одиниці]),
    [Частота], [12], [МГц],
  ),
  caption: [Параметри мікроконтролера],
) <tab:params>
```

- Шаблон таблицю не змінює: `align`, `stroke`, `fill`, `table.hline`, `set table(...)`, `show table.cell` працюють як звичайно. `supplement: [Табл.]` змінює назву, але напис продовження лишається «Продовження таблиці». Обгортка -- `grid`, тож `show grid.cell` зачепить і її.

## Формули

```typst
Частотну ефективність обчислюємо за @eq:eff[формулою]:
$ beta = gamma / (2^gamma - 1) $ <eq:eff>
#utils.noindent де $gamma = 1.5$ -- частотна ефективність, біт/(с·Гц); $beta$ -- енергетична ефективність.

Проміжна оцінка без посилання номера не отримує:
$ f(1.5; 2.5) = 0.85 dot beta $
```

- Номер праворуч -- лише у виносної формули з міткою, на яку є посилання (7.10.2). Без посилання номера немає, пропусків у нумерації не буде. Номери: (1.1), (1.2); у додатках (А.1); у багаторядкових -- по останньому рядку.
- Формули в рядку (`$x^2$`) не нумеруються.
- Пояснення познак -- з нового рядка `#utils.noindent де …`, без двокрапки після «де» (7.10.6).
- Десяткові дроби -- крапкою (`$9.8$` → «9,8»); аргументи з дробами -- через `;`.

## Код і лістинги

````typst
```c
int main(void) { return 0; }
```

#figure(
  ```bash
  for f in *.txt; do wc -l "$f"; done
  ```,
  caption: [Підрахунок рядків у файлах],
) <lst:count-lines>

#raw(read("assets/sample.c"), lang: "c", block: true)
````

- Блок коду -- Courier New 11 pt з відступом.
- Лістинг з підписом -- `figure` з блоком коду: «Лістинг 1.1 – …» над кодом, довгий переноситься з «Продовження лістингу 1.1» / «Кінець лістингу 1.1». `placement: top` не розривається.
- Великі файли не копіюй у `.typ` -- читай `#raw(read("…"), lang: "…", block: true)` (файл має бути в `src/`).
- Рядковий код `` `ls -la` `` виводиться звичайним текстом у лапках «ls -la» (ДСТУ). Моноширинний: `#show: style.overrides.inline-code` (можна `.with(fill: luma(240))`).

## Примітки

```typst
#note[Пояснення до попереднього тексту.]          // Примітка. Пояснення …
#note[Перша примітка.][Друга примітка.]           // Примітка 1. … Примітка 2. …
```

Слово «Примітка» не пиши -- його додає шаблон. Кегль 12, одинарний інтервал, абзацний відступ, подвійний інтервал від тексту. До рисунка чи таблиці -- `note:` у `fig`/`tab`.

## Виноски

```typst
Текст#footnote[Пояснення до тексту.] далі.
```

Знак «1)», нумерація з 1 на кожній сторінці, кегль 12, лінія 35 мм. Не більше 4 виносок на сторінці (7.9.3) -- стежить автор.

## Посилання

| Розмітка | Результат |
| --- | --- |
| `@sec:analysis` / `@sub:analogues` / `@pt:first` | Розділ 1 / Підрозділ 1.1 / Пункт 1.1.1 |
| `@fig:scheme` | Рисунок 1.1 |
| `@fig:scheme[рисунку]` | рисунку 1.1 |
| `@tab:measurements[таблиці]` | таблиці 1.1 |
| `@eq:einstein` | Рівняння (1.1) |
| `@eq:einstein[формулою]` | формулою (1.1) |
| `@lst:count-lines` | Лістинг 1.1 |
| `@app:code[додатку]` | додатку А |
| `@mysql` (ключ з `bibl.yml`) | [1] (без власних `[...]`, інакше «[[1]]») |

Слово в дужках замінює підпис -- так узгоджують відмінок. Префікси міток: `sec:`, `sub:`, `pt:`, `fig:`, `tab:`, `eq:`, `lst:`, `app:`.

## Перелік джерел

`bibl.yml` у форматі Hayagriva:

```yaml
mysql:
  type: Book
  title: MySQL Language Reference
  author: Ab M.
  publisher: MySQL Press
  date: 2004
  page-total: 600

go:
  type: Web
  title: The Go Programming Language
  author: The Go Programming Language
  url:
    value: https://go.dev/
    date: 2024-12-10
```

- Використовуй лише `Book` (автор, назва, видавництво, рік, кількість сторінок) і `Web` (назва, автор чи організація, URL, дата звернення).
- `#bib(path("bibl.yml"), style: "3008")` -- перелік там, де стоїть, перед додатками.

| Аргумент | Значення |
| --- | --- |
| `style` | `"3008"` (типово) -- ДСТУ 3008:2015, `"8302"` -- ДСТУ 8302:2015 (для `cw-v2`), або CSL: `read("my.csl", encoding: none)` |
| `title` | Типово «Перелік джерел посилання» |
| `full` | `false` -- лише процитовані; `true` -- усі записи |

## Додатки

```typst
#show: style.appendices

= Код програми <app:code>
#raw(read("assets/main.c"), lang: "c", block: true)

= Знімки екрана
#fig(path("figures/screen.png"), [Головне вікно], label: <fig:screen>)
```

- Усе після `#show: style.appendices` -- додатки. Кожен `=` -- новий додаток з нової сторінки: «ДОДАТОК А» і назва нижче. Підрозділи «А.1», рисунки й таблиці «Рисунок А.1», формули «(А.1)».
- Літери без Ґ, Є, З, І, Ї, Й, О, Ч, Ь -- шаблон робить сам.
- В окремому файлі: `#style.appendices(include "chapters/appendices.typ")`.

## Шляхи до файлів

Рядок зі шляхом Typst шукає відносно файлу, де стоїть виклик. Для власних викликів (`image`, `read`, `csv`, `yaml`, `toml`) це зручно. Але рядок, переданий у функцію пакунка (`fig`, `bib`, `bib-path:`), шукатиметься в теці пакунка -- тому там лише `path("…")`.
